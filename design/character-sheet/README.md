# Character sheet source

Source of the [Fuzmo character sheet](https://claude.ai/artifact/1jP63BmDo9uJK3ch7EVr4n) canvas. `Fuzmo.dc.html` defines the character; every other board imports it with a `mood`. Keep its shapes in step with `../tools/render-fuzmo.mjs`, which renders the standalone SVGs in `../fuzmo/`.
